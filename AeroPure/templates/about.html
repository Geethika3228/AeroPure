About AeroPure

An end-to-end classical machine-learning analytics workspace built around the supplied OHLCV dataset.

SYSTEM ARCHITECTURE

  1. Data layerCSV loader reads the original market data without replacing the source of truth.
  2. Analytics layerEDA, preprocessing, linear models, tree models, clustering, PCA, and evaluation.
  3. Serving layerFlask routes expose dashboard pages and generated visual outputs.
  4. Engineering layerArtifacts, monitoring signals, testing, and retraining concepts.

PROJECT SCOPE

AeroPure owns classical supervised and unsupervised machine learning plus introductory ML engineering. The six modules are designed to map directly to the supplied syllabus while keeping every practical result tied to the actual dataset.
